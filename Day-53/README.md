# AIML Day 53 – Regression with Keras

## Topic: Regression – Predicting a Number, Not a Class

### Concepts Learned

- Introduction to Regression.
- House Price Prediction using Deep Learning.
- Splitting Features (X) and Target (y).
- Feature Scaling using StandardScaler.
- Target Scaling and Inverse Transformation.
- Building a Regression Model using Keras Sequential API.
- Dense Layers and ReLU Activation.
- Linear Output Layer (No Activation Function).
- Model Compilation using Adam Optimizer.
- Mean Squared Error (MSE) Loss.
- Mean Absolute Error (MAE).
- Model Training using fit().
- Model Evaluation using MAE and R² Score.
- Visualising Training Loss and Predicted vs Actual Values.

### Model Architecture

5 Input Features → 16 Neurons → 8 Neurons → 1 Output Neuron
