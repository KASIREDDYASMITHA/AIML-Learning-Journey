# Exploratory Data Analysis (EDA)
## 1. Introduction to EDA

EDA stands for Exploratory Data Analysis.

Exploratory Data Analysis is the process of examining,
analyzing, and understanding a dataset before applying
Machine Learning algorithms.

EDA helps us understand the structure, patterns,
relationships, and problems in the dataset.

### Objectives of EDA

1. Understand the dataset.
2. Identify numerical and categorical features.
3. Find missing values.
4. Detect outliers.
5. Understand the distribution of data.
6. Identify relationships between features.
7. Select relevant features for Machine Learning.
8. Visualize the data.

### Importance of EDA

- Helps understand the dataset.
- Helps identify data quality problems.
- Helps detect missing values and outliers.
- Helps identify useful features.
- Helps select appropriate preprocessing techniques.
- Helps make better decisions before model building.

---

## 2. Main Steps in EDA

The main steps involved in EDA are:

1. Data Understanding
2. Data Cleaning
3. Feature Selection
4. Handling Missing Values
5. Statistical Analysis
6. Data Visualization
7. Hypothesis Investigation

These steps help us understand and prepare the dataset
before building a Machine Learning model.
