# Day 51 - Building Neural Networks with Keras

## Overview
Today I learned how to build, train, and evaluate neural networks using TensorFlow Keras for binary and multiclass classification.

## Topics Covered
- Introduction to Keras and Sequential models
- Dense layers and activation functions
- Binary classification using customer churn prediction
- Data preprocessing, encoding, and feature scaling
- Training and evaluating neural networks
- Multiclass classification using the MNIST handwritten digits dataset
- Flatten layer, ReLU, and Softmax
- Binary cross-entropy and sparse categorical cross-entropy
- Loss and accuracy curves
- Understanding overfitting

## Programs
1. `binary_classification_keras.py` - Builds a neural network to predict binary class labels.
2. `multiclass_classification_mnist.py` - Builds a neural network to classify handwritten digits from 0 to 9.

## Key Learning
Keras automates the construction, forward propagation, and training of neural networks. The fundamental concepts remain the same: weights, biases, activation functions, loss functions, and optimization.
