# Day 50 - Multilayer Perceptron (MLP) Architecture

## Overview
Today I learned how a Multilayer Perceptron (MLP) is organized
into input, hidden, and output layers.

## Topics Covered
- MLP architecture and layers
- Neurons and fully connected layers
- Weights, biases, and parameters
- Network width and depth
- Matrix multiplication and dot products
- Forward propagation
- Activation functions and ReLU
- Matrix shapes and batch processing
- Parameter counting
- Output layers for regression, binary classification,
  and multiclass classification

## Key Equations

Weighted sum:
z = W @ a_previous + b

Activation:
a = activation(z)

Batch processing:
Z = X @ W.T + b
