## Core Formula

ŷ = mx + b

Where:

- `ŷ` = predicted output
- `x` = input
- `m` = slope
- `b` = intercept

## Main Objective

Find the values of `m` and `b` that produce the minimum total squared error.

## Key Takeaway

Linear Regression finds the best straight line that represents the relationship between input and output data and uses that line to make predictions.
