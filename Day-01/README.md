## Day 1 Goal

The main goal of Day 1 was to understand that Machine Learning is not only about selecting algorithms. A good ML practitioner should first understand the problem, identify the required output, choose the appropriate learning paradigm, verify the data, define the evaluation metric, select suitable models, and evaluate them fairly.
