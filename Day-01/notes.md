# Day 01 — Machine Learning Fundamentals

## 1. What is Machine Learning?

Machine Learning is a way of building computer programs that improve their performance on a specific task through experience or data rather than being explicitly programmed with all the rules.

A formal definition of Machine Learning:

> A program learns from experience E with respect to a task T and performance measure P if its performance P on task T improves with experience E.
