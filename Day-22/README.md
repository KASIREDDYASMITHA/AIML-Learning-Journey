## Key Learning

Classification models should not be evaluated using accuracy alone, especially when the classes are imbalanced.

Precision is important when false positives are costly.

Recall is important when false negatives are costly.

F1 Score provides a balance between precision and recall.

The classification threshold affects precision and recall.
