# Day 54 - Activation Functions

## Overview
Today I learned about Activation Functions in Artificial Neural Networks (ANN).

An activation function transforms the raw weighted sum (z) of a neuron into its output (a). It introduces non-linearity, allowing neural networks to learn complex patterns.

## Topics Covered
1. Step Function
2. Linear Activation Function
3. Sigmoid Function
4. ReLU (Rectified Linear Unit)
5. Leaky ReLU
6. Softmax Function

## Key Concepts
- Meaning and importance of activation functions.
- Why non-linearity is required in neural networks.
- Mathematical formulas of activation functions.
- Advantages and disadvantages of each function.
- Dying ReLU problem.
- Vanishing Gradient problem.
- Choosing activation functions based on the task.

## Applications
- Hidden Layers: ReLU (default), Leaky ReLU.
- Regression Output: Linear.
- Binary Classification Output: Sigmoid.
- Multi-class Classification Output: Softmax.
- Step Function: Historical perceptron.
