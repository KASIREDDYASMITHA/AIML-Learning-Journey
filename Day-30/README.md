# DSA Day 30 - Stack and Queue 

## Topics Covered

1. Maximum Rectangle in Skyline
2. Brute Force Approach
3. Nearest Smaller Element on Left and Right
4. Left and Right Boundary Approach
5. Optimized Stack Approach
6. Min Stack
7. Stack Operations: Push, Pop, Top, and Get Minimum

## Python Programs

| S.No | Program | Approach | Time Complexity |
|------|---------|----------|-----------------|
| 1 | Maximum Rectangle | Brute Force | O(n^2) |
| 2 | Maximum Rectangle | Left and Right Boundaries | O(n^2) |
| 3 | Maximum Rectangle | Monotonic Stack | O(n) |
| 4 | Min Stack | Encoded Minimum | O(1) per operation |

## Key Learnings

- Finding the maximum rectangular area in a histogram.
- Finding the nearest smaller element on the left and right.
- Calculating the width and area of a rectangle.
- Using a monotonic stack to optimize the solution.
- Implementing a Min Stack with constant-time operations.
- Understanding how to encode values to track the minimum.
