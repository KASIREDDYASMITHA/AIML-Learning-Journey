# Day 46 — Perceptron to MLP

## Overview

Today I learned how to implement a Perceptron from scratch and understand its limitations using the OR and XOR logic gates.

## Topics Covered

- Forward pass and step activation function
- Loss calculation
- Weight and bias updates
- Training loop and epochs
- OR gate classification
- XOR linear separability problem
- Multi-Layer Perceptron (MLP)
- Hidden layers and ReLU activation
- MLPClassifier using Scikit-learn
