# AIML Learning Journey - Day 24

## Topic: End-to-End Machine Learning Workflow

Today I learned how a Machine Learning project moves from a problem statement to a deployable model.

### Topics Covered

- Problem framing
- Feature engineering
- Data cleaning and exploration
- Choosing evaluation metrics
- Building a baseline model
- Train-test split
- Model training
- Regression for continuous outputs
- Model evaluation
- Experiment tracking with MLflow
- CI/CD for ML systems
- Docker for consistent environments
- Deployment, storage and scaling

### Example Problem

Predicting the delivery time of a customer order.

The target is a continuous value, so this is a regression problem.

### Key Learning

A Machine Learning system is not only about training a model. A complete ML workflow includes data preparation, feature engineering, evaluation, experimentation, deployment and monitoring.
