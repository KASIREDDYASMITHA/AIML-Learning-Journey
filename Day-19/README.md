## Key Learning

A classification model should not be judged using accuracy alone.

Different problems require different evaluation metrics:

* Cancer screening → Recall is important
* Spam filtering → Precision is important
* Credit card fraud detection → F1 Score is useful

The threshold used to convert probabilities into class labels also affects Precision and Recall.
