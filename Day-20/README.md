## Key Learning

Today I learned how to evaluate classification models properly instead of depending only on accuracy. Different evaluation metrics are useful depending on the real-world cost of False Positives and False Negatives.

The 0.5 classification threshold is not always the best choice. The correct threshold depends on the problem and the required balance between Precision and Recall.
