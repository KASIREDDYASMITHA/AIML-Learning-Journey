# AIML Learning Journey - Day 26

## Pandas and Data Cleaning

Day 26 focused on basic Pandas operations used for filtering data, handling multiple values stored in a single column, and analyzing numerical columns.

### Topics Covered

- Pandas `loc` for label-based filtering
- Filtering rows using conditions
- Splitting comma-separated values using `str.split(',')`
- Converting text/numeric columns using `astype(float)`
- Using `describe()` for numerical statistics
- Understanding dataset size and unique values

### Dataset Observation

The class dataset contained:

- 45,593 rows
- 1,320 unique `rider_id` values

This means that multiple ride records can belong to the same rider.
