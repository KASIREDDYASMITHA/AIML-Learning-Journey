## Key Takeaway

A Decision Tree that is too simple can **underfit**, while a tree that is too complex can **overfit**. The goal is to find the right level of complexity where both training and test performance are high and close to each other.

The main diagnostic is the **training-test accuracy gap**.

## Hyperparameter Tuning Order

1. Max Depth
2. Min Samples Split
3. Min Samples Leaf
4. Max Features
5. Criterion
