### Types of Loss Functions

**Regression Losses:**
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- Huber Loss

**Classification Losses:**
- Binary Cross-Entropy (BCE)
- Categorical Cross-Entropy (CCE)

### Key Learning

- Loss functions measure the difference between actual and predicted values.
- Lower loss generally indicates better predictions.
- MSE penalizes larger errors more heavily.
- MAE treats errors proportionally.
- Huber Loss combines the advantages of MSE and MAE.
- Binary Cross-Entropy is used for binary classification.
- Categorical Cross-Entropy is used for multi-class classification.
- Loss values are used during backpropagation to update network weights.
