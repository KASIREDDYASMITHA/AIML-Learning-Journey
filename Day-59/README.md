
# Day 59 - Backpropagation From First Principles

## Overview
Today I learned the fundamentals of Backpropagation and how a neural network's loss is connected to its weights, biases, and intermediate calculations.

## Topics Covered
- Understanding how a neural network learns.
- Trainable parameters: Weights and Biases.
- Forward Propagation and Loss Calculation.
- Understanding the dependency chain.
- Relationship between Loss and Prediction.
- Relationship between Prediction and Pre-activation.
- Hidden Layer and Output Layer dependencies.
- Backward direction of Backpropagation.
- Why Backpropagation starts from the Loss.
- Introduction to the Backpropagation algorithm.

## Network Architecture
2 Inputs → 1 Hidden Neuron (ReLU) → 1 Output Neuron (Linear)

## Practical Example
Input: [1, 1]
True Output: 1.0
Predicted Output: 0.77
MSE Loss: 0.0529 (approximately 0.053)
