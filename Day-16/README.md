## Key Learning

Information Gain measures how much entropy decreases after a split.

The Decision Tree repeatedly selects the split with the **highest Information Gain** and builds the tree recursively.

For numerical features, the tree tests different threshold values and chooses the best one.

Hyperparameters control the complexity of the tree and help prevent overfitting.
