# Day 51 - Building Neural Networks with Keras

## Topics Covered
- Introduction to Keras and Sequential models
- Dense layers and activation functions
- Binary classification using customer churn prediction
- Data preprocessing and feature selection
- One-hot encoding of categorical features
- Train-test splitting and feature scaling
- Neural network training using model.compile() and model.fit()
- Binary cross-entropy loss
- Multi-class classification using the MNIST dataset
- Flattening images and normalizing pixel values
- ReLU and Softmax activation functions
- Model evaluation using accuracy
- Loss and accuracy curves
- Understanding overfitting


## Key Learnings
- Keras simplifies neural network implementation.
- Binary classification uses one output neuron with sigmoid activation.
- Multi-class classification uses multiple output neurons with softmax activation.
- Feature scaling helps neural networks learn effectively.
- Validation metrics help monitor model performance.
- The loss function depends on the classification problem.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Learning Goal
Understand how to build, train, evaluate, and make predictions
using neural networks with Keras.
